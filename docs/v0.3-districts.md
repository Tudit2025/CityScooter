## 数据契约（代码：`Scripts/Runtime/Track/District.cs`、`Ramp.cs`、`RoadGap.cs`）

### 路段横截面（所有场景必须遵守，任意两个场景才能首尾相接）

- 每个路段**开头和结尾**都是标准街道截面：`halfWidth 4`、`sidewalkWidth 4`、`sidewalkHeight 0.2`、`curbTransitionWidth 0.3`。
  - 中间可以变宽或变窄（`endHalfWidth`），但场景自己的路段顺序要把它变回来。
- 长度是 10 m 的整数倍（标准 40 m）。
- 坡度 `endHeight`：标准是每 40 m 约 -3.1471（4.5° 下坡）。河边可以平一点，Kings Park 下坡可以陡一点，范围是每 40 m 在 -8 到 0 之间。
- `RoadChunk` 只读这个组件、`SpawnSlot` 子物体和 `Obstacle` 上的碰撞体。生成列 x = -2.6/0/2.6，生成行 z = 10/25（每 40 m）。

### 场景之间的过渡

- 生成器先放旧场景的 `exit`，再放新场景的 `entry`。
- 过渡段的外侧一端要"安静下来"：建筑变矮，换成树、绿篱、矮墙，这样两个场景的交界处不会出现硬切。
- 雾色、天空色调、环境光、阳光在交界前后 `blendMeters`（默认 150 m）内渐变。
- 交界处尽量落在一个假转弯里：新场景从拐角后出现。
- 入口门牌写场景名，HUD 提示 `ENTERING KINGS PARK`，同时发给板子 `zone:kingspark`。

### 跳台 `Ramp` 和缺口 `RoadGap`

- **`Ramp`**：
  - 坡段长 `rise`，升到 `height`；平台段长 `top`（0 就是小跳台）；然后是台边，过了台边就起飞。
  - 起飞向上的速度 = 速度 × 坡度 × `launch`；滞空时重力 × `hangGravity`（越小飞得越久）。
  - 宽 `width`，侧面撞上不算撞车。台面上可以放障碍。
- **`RoadGap`**：一段没有地面的区域（河湾、高架步道尽头的缺口）。
  - 在地面上骑进去就掉下去，算撞车，显示 `word`，比如 SPLASH。
  - 飞过去就没事。
  - 横跨整条路的缺口前面**必须**有跳台。
- 跳台和缺口可以做在路段里（作为路段的子物体），也可以由生成器按 `District.ramps` 和 `rampFrequency` 放在路上。

## 美术规范（同 `docs/art/comic-city-standard.md`）

- 用技美的漫画几何库：`ComicMesh`、`ComicKitGeometry`、`ComicPalette.mat` 和 `ComicInk.mat` 两个共享材质，顶点色。
  - 不加新材质、贴图、着色器。水面也用顶点色的平板。
- 预算：每个路段含描边不超过 25k 三角形、不超过 8 个渲染器。远排建筑、路面、远景不投影。
- 地标做成风格化剪影，不放商标或品牌文字。
  - 牌子上只写地名，用像素字体。
  - 战争纪念碑之类只做背景，**不能做成可以撞或可以打的东西**。
- 动物（孔雀、黑天鹅、鹈鹕、喜鹊）：`Obstacle.kind = Person`，`animal = true`，`punchable = false`。
  - 出拳只会把它们吓跑，卡通模式也不会把它们撞飞。
  - 撞上了照样算撞车，提示是 SORRY!。
- 参考资料：
  - 用 `yt-dlp` 拿 YouTube 视频的预览帧（storyboard），封面大图从 `https://i.ytimg.com/vi/<id>/maxresdefault.jpg` 取；Wikimedia Commons 上的照片也可以。
  - 参考图放在仓库外面的 `D:\CityScooter-refs\<id>\`，**不进仓库、不进游戏**；只把链接写进 `SOURCES.txt`。
  - 命令：

    ```
    yt-dlp --no-update --js-runtimes node -f sb0 -o "D:/CityScooter-refs/<id>/<video>/sb.%(ext)s" <url>
    python -I tools/refs/storyboard_frames.py D:/CityScooter-refs/<id>/<video>/sb.mhtml D:/CityScooter-refs/<id>/<video>/sheets
    ```

    完整视频下载会 403，预览帧可以。
  - 已找到的视频：UWA `YIswSbhA_6s`、`LigEg2-vkgY`；Mounts Bay `WTtoAMZY4y0`、`COe3VzBYowg`；Kings Park `q317YxcPncQ`、`qugqw3DTBhE`；CBD `-ja--f3D5tE`。
  - 用 `yt-dlp --flat-playlist --print "%(id)s | %(title)s" "ytsearch8:<查询>"` 找更多。

- **系统 A：场景系统**

  - 测试。
- **系统 B：跳台和滞空**
  - 骑手顺着台面起伏，台边起飞，滞空重力，空中转向，落地。
  - 缺口掉下去算撞车（SPLASH）。
  - 镜头跟着抬高；跳台后的空中礼物弧线。
  - 通用跳台预制体：小跳台、平台。
  - 协议：`air:1`、`air:0`、`land:ok`；板子发 `trick` 做特技（翻转、转体）加分；`do:ramp`。
  - 积木，测试。
- **美术 1**：UWA、Matilda Bay。
- **美术 2**：Kings Park、Mounts Bay Road。
- **美术 3**：Perth CBD、Elizabeth Quay。

每个场景都要有：
- 4～6 种路段，加 entry 和 exit；
- 2～4 种场景专属障碍或路人；
- 1～2 种场景专属跳台：栈桥、台阶、高架步道缺口、停车场坡道、桥拱；
- 雾和光的配色；
- 远景（可选）；
- 游戏视角预览图。
