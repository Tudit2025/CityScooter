# CityScooter 协议 v1

v1（2026-11-07）在 v0 上只**加**消息：板子可以发出拳 `pu`、按铃 `bl`；游戏会发 `ko`、`warn:…`、`turn:…`。11/8 又加了西澳警察（通缉星级、警车追捕、直升机撒网和狙击）：板子可以发投降 `sur`，游戏会发 `wanted:N`、`chase:…`、`cop:N`、`heli:…`、`inc:…`、`arrested`、`busted`、`lost`。v0 的学生代码不用改，不认识的消息会被跳过。

学生写的 micro:bit 程序和游戏之间只说这一种"话"。每条消息一行，ASCII 文本，以换行 `\n` 结尾。
USB 串口波特率 115200。v0 只用于 USB 直连和模拟器；无线（radio）版在第 2 周基于同样的消息再设计。

代码里的定义：`Assets/_Project/Scripts/Protocol/Messages.cs`，解析规则和单元测试见同目录与 `Assets/_Project/Tests/EditMode/`。

## micro:bit → 游戏

| 消息 | 含义 | 学生代码写法（MicroPython） |
|---|---|---|
| `st:-35` | 转向，-100（最左）到 100（最右），超出会被截断；允许小数 | `print("st:" + str(steer))` |
| `jp` | 跳一下（在空中重复发不会多跳） | `print("jp")` |
| `br` | 刹车。每条维持 0.3 秒，按住就每个循环发一次 | `print("br")` |
| `hi:v2` | 报告板子版本（可选，游戏显示用） | `print("hi:v2")` |
| `pu` | **v1** 出拳：把前方左右 2.5 m 内最近的纸箱、垃圾桶、锥桶打飞，打中游戏回 `ko`。冷却 0.4 秒，冷却中发的不算。人、车、路障打不动 | `print("pu")` |
| `bl` | **v1** 按铃：前方 30 m 内的行人让到一边，头上冒"!" | `print("bl")` |
| `do:事件` | **v1** 让游戏发生它自己的事件（**v0.3** 加了 `ramp`：在你这条车道前方看不到的地方放一个跳台，落地区的障碍会清掉）：`chase`（警方追击）、`stars:0`～`stars:5`（设定通缉星级，0 是警察放弃）、`heli`（直升机，至少 3 星）、`calm`（警察放弃）、`turn:L` / `turn:R`（前方安排一个弯）、`car`（对向车）、`slowcar`（前面的慢车）、`roadworks`（路政）、`police`（警察拦路）、`crossing`（行人过马路）、`manhole`（窨井）。骑行中每块板每秒最多 1 次；两局之间（开局画面、撞车后的结算画面）发的先记下来，下一局开始 0.4 秒后执行，同一种事件只记最后一次；路段事件放在前方看不到的地方，不会放在大马路的过渡路段上。之后照常收到 `chase:1`、`wanted:N`、`warn:car` 这些消息 | `print("do:chase")` |
| `say:party` | **v1** 让游戏说一个自己的词：游戏把 `party` 转发给**所有**连着的板子（包括发的这块），并在屏幕上显示是谁说的。规则：一个词，字母、数字和 `_ - ! ?`，最长 16 个字符；不能是游戏自己的消息（`crash`、`gift`、`go` 等，也不能带冒号），否则监视器会提示格式不对；每块板每秒最多 2 次，多的不转发 | `print("say:party")` |
| `bo` | **v1** 加速：2 秒内速度提到上限的 1.35 倍。冷却 6 秒，冷却中发的不算 | `print("bo")` |
| `toon:1` / `toon:0` | **v1** 卡通模式开/关。开着时撞到行人不算撞车：人"BOING!"一声飞出去，你减速，出拳也能把人打飞；关着时撞人就是撞车。游戏记住最后一次收到的值（只发 `toon` 也算开）。程序一开始就发的那条可能游戏还没收到，所以放在循环里或按钮里发 | `print("toon:1")` |
| `trick` | **v0.3 跳台** 在空中做特技：从跳台飞起来以后（收到 `air:1` 之后）第一次是转体 SPIN，第二次是后空翻 FLIP，轮流来，每个 0.6 秒，各加 50 分；一次飞行里做完 2 个以上，安全落地时每个再加 25 分（COMBO）。正在做的时候再发一条会排在后面（最多排 1 条）。落地时特技还没做完：不算撞车，显示 SKETCHY!，这一个不加分。在地上、普通小跳里发了不算。3 秒内发了 6 条以上（在地上发的也算）就会"头晕"，3 秒内不能做特技，所以放进 forever 里一直发没用。`trick:1` 也认。键盘 `Q` | `print("trick")` |
| `sur` | **v1 警察（11/8）** 投降：被警察追的时候马上靠边停车（自动刹车到停下），停稳 1.5 秒后 ARRESTED。没被追时发了不算。`sur:1` 也认 | `print("sur")` |

- 推荐循环 `sleep(50)`，也就是每秒 20 次左右。转向超过 0.5 秒没更新，游戏会把转向归零（拔线、程序报错时车不会一直往一边跑）。
- 一帧内收到多个 `jp` 只算一次。轮询写法 `is_pressed()` 会每秒发几十个 `jp`，游戏不会出错，但串口监视器会把这个次数显示出来，第 4 课正好用来讲事件写法和轮询写法。
- **任何不认识的行都不算错误**：学生自己的 `print`、Python 报错（Traceback）都原样显示在串口监视器里。
- 格式宽松：大小写不敏感，冒号两边可以有空格（`ST : 20` 也认）。`st:abc` 这种值不对的会标成"格式不对"，监视器给提示。

## 游戏 → micro:bit

| 消息 | 什么时候发 |
|---|---|
| `go` | 新的一局开始 |
| `crash` | 撞车 |
| `gift` | 捡到礼物 |
| `spd:0` … `spd:9` | 实际速度相对当前速度上限的档位，变化时才发，每秒最多 5 次；上限可随本局进度增长 |
| `ko` | **v1** 出拳打中了 |
| `boing` | **v1** 卡通模式下撞飞了一个人 |
| `tired` | **v1** 拳出完了（最多连出 3 拳，每 1.2 秒恢复 1 拳），这时发的 `pu` 不算；每秒最多发一条 |
| `warn:car` / `warn:ped` / `warn:hole` | **v1** 自己这条路上（左右 1.3 m 内）前方有车、有人、有坑：25 m 或 1.5 秒车程内，取远的那个。同一个东西 8 秒内只发一次，所有警告合起来每秒最多 4 条（V1 的串口缓冲小） |
| `turn:-1` / `turn:1` / `turn:0` | **v1** 路开始往左弯、往右弯、回到直道（假拐弯，路在物理上还是直的；难度 3 级以后拐弯会把人往弯外推一点，要往弯里转向） |
| `wanted:0` … `wanted:5` | **v1 警察** 通缉星级，变了才发。打警察、打警车一次加 1 星（最多 5 星）；甩掉警察或者一阵子不再打警察会掉星。新的一局开始时如果不是 0，会在 `go` 之后补发 `wanted:0` |
| `chase:1` / `chase:0` | **v1 警察** 警车开始追你 / 追捕结束（甩掉了、被抓了、撞车了） |
| `cop:0` … `cop:9` | **v1 警察** 追你的警车在多远：大约每 10 m 一档，0 就是贴着你，9 是很远或者暂时没有警车。只在被追时发，变化时才发，每秒最多 3 条。追捕结束后不再发：自己的程序在收到 `chase:0` 或 `go` 时把它当成 9（积木生成的代码会自动这样做） |
| `heli:1` / `heli:0` | **v1 警察** 警用直升机来了（3 星以上）/ 走了 |
| `inc:L` / `inc:C` / `inc:R` | **v1 警察** 直升机要撒网的靶圈出现了、或者狙击红点锁定了：在你左边 / 就在你身上 / 在你右边。网从靶圈出现到落下至少 0.8 秒，`inc:C` 时往旁边躲（网也可以刹车躲）就躲得开；红点锁定后闪 0.7 秒（5 星 0.55 秒）开枪，要往旁边挪开。注意大写字母 |
| `arrested` | **v1 警察** 被抓（ARRESTED）：被追时停下来了（刹到很慢、或者发了 `sur`），或者警车在旁边贴着你 1.5 秒，或者被直升机的网罩住（"NETTED!"）。这一局结束，紧跟在 `crash` 后面发 |
| `busted` | **v1 警察** BUSTED：被警车撞了，或者被直升机上的狙击手打中（漫画式摔下车，没有血）。这一局结束，紧跟在 `crash` 后面发 |
| `air:1` / `air:0` | **v0.3 跳台** 从跳台飞起来了 / 落地了（或者在空中撞车、掉进水里，这时 `air:0` 在 `crash` 前面）。每次飞行各发一次。普通跳（`jp`）只飞 0.65 秒，**不发**；只有从跳台起飞，或者预计能飞 0.8 秒以上的（比如在高平台上起跳）才发（`GameTuning.airMessageMinSeconds`） |
| `land:ok` / `land:trick` | **v0.3 跳台** 安全落地，紧跟在 `air:0` 后面：这次飞行里至少做完 1 个特技是 `land:trick`，否则 `land:ok`。掉进缺口（SPLASH!）、落在车上撞车时没有 `land:` |
| `lost` | **v1 警察** 甩掉警察了（LOST THEM!）：星级掉到 0。加分只算打警察挣来的星（每颗 100），`do:stars` 这类程序给的星不加分 |
| `zone:uwa` … | **v0.3 场景** 你在哪个场景（沿 UWA → 珀斯市中心的真实骑行线）：一局开始时在 `go` 后面发一次出发的场景，之后每骑进下一个场景发一次（几百米一次，很少）。id 按路线顺序：`uwa`（UWA）、`matilda`（Matilda Bay）、`kingspark`（Kings Park）、`westperth`（West Perth）、`cbd`（Perth CBD）、`quay`（Elizabeth Quay）、`mountsbay`（Mounts Bay Road），走完再回到 `uwa`。只有小写字母。屏幕上同时显示 `ENTERING KINGS PARK` |

键盘对应：`F` 出拳，`R` 按铃，`E` 加速，`T` 卡通模式开/关，`Q` 特技（v0.3；外壳关掉键盘时这些键都不起作用，板子发的 `trick` 照样有效）。

**跳台和缺口（v0.3）：**
- 路上会出现跳台（小跳台、带平台的高跳台），骑上去自然升高，过了台边就飞起来，在空中能少量转向，落在路上或者另一个跳台上。飞行轨迹上挂着一串礼物，只有飞起来才拿得到。
- 有的路段有缺口（河湾、高架步道尽头）：在地上骑进去会掉下去，显示 SPLASH!（水）或 WHOOPS!（落空），这一局结束，板子收到 `crash`。飞过去就没事，落在缺口里一样会掉下去。缺口前面一定有跳台。
- 一次飞行的消息顺序：`air:1` → （特技）→ `air:0` → `land:ok` 或 `land:trick`。这几条很少（几秒最多一次），V1 的串口缓冲够用。被追时按住 `S` 刹车就是靠边停车。

**警察消息的顺序和频率（11/8）：**
- 一局因为警察结束时，`arrested` 或 `busted` 总是**最后一条**，前面一定有 `crash`；正在追的话还会有 `heli:0`（直升机在的话）和 `chase:0`。所以"收到 `crash` 显示哭脸、收到 `busted` 显示别的"这种写法，最后留在屏幕上的是 `busted` 的。被追时撞到别的东西：`crash`、`heli:0`、`chase:0`，没有 `busted`。
- 甩掉警察时的顺序是 `wanted:0`、`chase:0`、`lost`。
- `cop:` 每秒最多 3 条，`inc:` 两条之间至少隔 0.15 秒（5 星时一次两个靶圈会连着发两条），其他警察消息很少，发生时马上发。加上 `spd:` 和 `warn:`，V1 的串口缓冲也够用。
- 第一课的程序不认识这些消息，会直接跳过，照样能玩。

**狂发没用（11/8 加的规则，数值在 `GameTuning` 的 "Punch and bell limits"）：**
- 出拳：拳头伸出去时转向只剩 30%（一只手离开车把）；最多连出 3 拳，然后 `tired`；打空扣 5 分，打中加 15 分；结算显示命中率。
- 按铃：冷却 1 秒；5 秒内按超过 3 次，行人 3 秒内不理你（头上冒"…"）。
- 卡通模式：每撞飞一个人花 1 个礼物；没有礼物时撞人就是撞车。
- 加速：冷却 6 秒。
- 最好的写法是收到 `warn:` 再出手，而不是放进 forever 里一直发。（`B` 在所有提示里都是板子上的刹车键，所以按铃不用 B）。

**场景消息（v0.3）：**
- `zone:` 只有游戏发，板子发了游戏不理（网页的串口监视器会提示"这是游戏发的消息"）。`say:zone:uwa` 也不行（带冒号）。
- 主题里只有一个场景时没有交界，只在开局发一次。
- 积木"when entering [Kings Park]"，或者"when the game says"里的 `zone:kingspark`，生成的都是一个 `elif msg == "zone:kingspark":` 分支，V1 也放得下。
- 开局画面显示出发场景（"Start: UWA"）。键盘开着时按数字键 1～7 换出发场景（老师演示用）；键盘关掉时（只用 micro:bit）不提数字键，按了也没用。默认出发场景在 `GameTuning.startDistrict`。

### 学生代码必须先攒到换行再处理

MicroPython 的 `uart.readline()` 不会等一整行到齐，有多少字节就返回多少。2026-11-05 在模拟器里实测：`crash` 被读成了 `cr` 和 `ash` 两半。真板子出现的概率小一些，但也会有。所以起步代码统一用下面这个函数（已在模拟器里验证）：

```python
buf = ""

def messages():
    # uart.readline() can return half a line, so collect bytes until a newline arrives.
    global buf
    out = []
    if uart.any():
        data = uart.read()
        if data:
            buf += str(data, "utf-8")
            while "\n" in buf:
                line, buf = buf.split("\n", 1)
                out.append(line.strip())
            if len(buf) > 100:
                buf = ""
    return out
```

主循环里写 `for msg in messages(): ...`。另外别忘了 `uart.init(baudrate=115200)`。不带参数的 `uart.init()` 会把波特率改成 9600，游戏就收不到了。

## V1 / V2 兼容

起步代码只用两代都有的功能：`accelerometer`、`button_a/b`、`display`、`Image`、`music`（V1 没有扬声器，不出声但不报错）、`uart`、`sleep`。

只有 V2 有的功能放进加分题：`microphone`（喊叫跳跃）、`pin_logo`（触摸 logo）、`audio`/`Sound` 表情音。判断版本的写法：

```python
try:
    from microbit import microphone
    VER = "v2"
except ImportError:
    VER = "v1"
```
