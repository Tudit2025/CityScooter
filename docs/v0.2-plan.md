## 2. 需要老师拍板的事

1. **出拳打谁**（第 6 节）。我的建议：出拳只打**对手车手**和**俯冲的喜鹊**，行人、工人、警察都不能打；遇到行人要**按铃**让路，撞上行人就算撞车。理由：这是学校的课，家长和学校看到"打路人、打修路工"会有意见，而且打对手更像比赛，喜鹊又是珀斯每年春天的真实烦恼，学生有共鸣。程序上"能不能被打"是每个预制体上的一个开关，以后想改只改素材，不用改代码。
2. **警车和路政车的外观**：照西澳的风格做（警车白底、蓝白格子带、POLICE 字样、警灯；路政车橙黄斜纹、箭头灯板），但**不用真实的西澳警察局徽、"WA POLICE"字样，也不用西澳路政局（Main Roads WA）的标志**，避免商标和冒充的问题。
3. **拐弯要不要真的推人**（第 3 节）：拐弯时把骑手往弯外推一点，学生的转向代码就得跟着修正，拐弯才有手感。建议默认开，力度小（最多横向速度的 30%），难度 2 级以后才出现，第一课的任务不受影响。

## 3. 假拐弯（M1）

**做法**：和现在的"路往上弯"是同一招。技美的 `Art/Shaders/ComicWorldBend.hlsl` 已经在着色器里按"离骑手多远"把远处往上抬；我们再加一项**左右偏移**：`x += 弯度 × 距离²`（远处再接一段直线，和现在上抬的曲线同一形状）。

- **物理和碰撞完全不变**：路在逻辑上还是直的。现在的弯曲从骑手前方 32 m 才开始，32 m 以内画面和碰撞完全一致，所以不会出现"看着躲开了却撞上"。
- **节奏**：新脚本 `FakeTurnDirector` 按本局的随机种子排一串"直道 → 渐入左弯或右弯（2～4 秒）→ 保持（3～8 秒）→ 渐出"，通过一个全局着色器变量 `_ComicTurn` 告诉所有材质。弯度跟速度挂钩，速度越快弯越缓，免得远处甩得太厉害。
- **让人相信在拐弯**，光弯路面不够，还要四样：
  1. 天空全景和三层天际线按累计的"航向角"横向滚动，这是最关键的一项。
  2. 镜头往弯里侧倾 3～5°，视线稍微看向弯内。
  3. 骑手身体往弯里倾。
  4. 拐弯时加一点轮胎声（技美的音频库）。
- **路段事件可以触发拐弯**：比如"TAKE A DETOUR →"牌子之后接一个右弯，见第 4 节。
- **离心推力**（见第 2 节第 3 条）：拐弯时横向速度加上 `弯度 × 速度 × 系数`，系数在 `GameTuning` 里调。
- **要注意的**：所有场景里的材质都必须用会跟着弯的着色器（`ComicVertex`、`ComicOutline`），否则那个东西会"留在原地"。M1 做完时我会写一个测试，扫一遍场景和所有主题预制体，找出不跟着弯的材质。

**改动范围**：`ComicWorldBend.hlsl` 加一项（技美的文件，我改、技美审）；天空和天际线滚动（`ComicCityBackdrop` / `SkylineParallax`，技美的文件，同样我改技美审，或者技美自己做）；`FakeTurnDirector`、镜头、骑手倾斜、离心推力（Claude 的目录）。

## 4. 路段事件和更多障碍物（M2）

### 4.1 新的玩法组件

现在的生成器是"每个刷怪点随机放一个障碍或礼物"，放不出一整段路政区。新加的组件都放在 `Scripts/Runtime/Track/`（美术和玩法的对接目录）：

| 组件 | 作用 |
|---|---|
| `HazardPattern`（ScriptableObject） | 一段路段事件：一组"预制体 + 横向位置 + 前后位置"，加上长度、最低难度、权重，以及可选的"触发假拐弯（方向、力度）"。主题资源里列出这个主题能用哪些事件 |
| `Obstacle`（已有，加字段） | 加 `kind`：普通、车、人、坑。撞上之后的反应和发给板子的消息按 kind 区分 |
| `Mover`（新） | 会动的障碍：沿路前后开（对向车、同向慢车），或者横穿马路（行人）。由一个统一的系统在骑手移动**之前**更新位置，保证不穿模 |
| `Pedestrian`（新） | 行人的行为：在人行道上走、过马路、听到铃声让到一边 |
| `Punchable`（新） | 能不能被打，以及被打之后的反应（打转飞出、逃走）和加分 |

生成器的规则：路段事件优先，剩下的空位照旧随机放障碍和礼物。**每个路段事件都必须有一条能过的路线**，用一个编辑器测试验证：按骑手的最大横向速度和当前最高速，模拟能不能从事件里穿过去。验证不过的事件不允许进主题。

### 4.2 障碍物清单

澳洲靠左行驶：**对向来车走右侧车道，同向慢车走左侧**。道路宽 8 m，两侧人行道各 4 m，也能骑。

| 东西 | 行为 | 能跳过 | 出现在 |
|---|---|---|---|
| "ROAD WORK AHEAD"、"TAKE A DETOUR →"牌子 | 路边的提示，不挡路；DETOUR 牌之后接一个假拐弯 | — | 路政区开头 |
| 锥桶斜排 + 带闪灯的路障 | 把两条车道收窄成一条，或者把人赶上人行道 | 锥桶能，路障不能 | 路政区 |
| 路政维修车（箭头灯板闪） | 停着，占一条车道 | 不能 | 路政区 |
| 路政工人、举 STOP/SLOW 牌的交通指挥员 | 站着或慢慢走，撞上算撞车 | 不能 | 路政区 |
| 没盖的窨井（盖子掀在旁边，四周几个锥桶） | 地上的坑，必须跳或者绕 | 能（就是要跳） | 路政区、普通路段 |
| 对向来车 | 在右侧车道迎面开过来，50 m 外开始闪灯按喇叭 | 不能 | 2 级难度以后 |
| 同向慢车 | 在左侧车道慢慢开，要超过去 | 不能 | 1 级难度以后 |
| 警车 | 停在路边闪警灯，靠近时"呜"一声；以后可以做开出来 | 不能 | 偶尔 |

**一个完整的路政区**大概是这样：ROAD WORK AHEAD 牌 → 锥桶把路收窄 → 交通指挥员 → 维修车和工人 → 无盖窨井 → TAKE A DETOUR 牌 → 右弯 → 绕上人行道 → 人行道上有行人（这时就需要按铃，接第 5 节）。

**速度要注意**：现在一局开始的速度上限就是 44 m/s，5 分钟后到 132 m/s。对向车的出现距离、行人什么时候开始过马路，都要按**当前速度**算，保证从看见到撞上至少有 1.5 秒。

## 5. 行人、按铃和出拳（M3）

### 5.1 行人

- 人行道上有人来回走。路政区绕上人行道、或者路口有斑马线时，会有人过马路，什么时候开始过要算好：骑手到的时候他刚好在路中间，但旁边一定留一条能过的路。
- **按铃** `bl`：前方 30 m 内的行人听到会停下、让到一边，头上冒"!"。撞上行人算撞车，播"Sorry!"的气泡，不出血、不倒地，保持漫画风。

### 5.2 出拳（按第 2 节第 1 条的建议）

- **出拳** `pu`：打骑手左右 2.5 m、前方 4 m 以内最近的一个"能被打"的目标。冷却 0.4 秒，所以在循环里一直发 `pu` 没用，和第一课 `jp` 用 `is_pressed` 狂发的教学点是一样的，串口监视器里也显示"pu in 1 s"。
- **打中**会出漫画字"POW!"，游戏给板子发 `ko`。
- **能打的目标**：
  - **对手车手**：和你差不多快，每隔几秒往你这边挤；被挤到就晃一下、减速，不算撞车；打中就打转飞出去，加分。
  - **俯冲的喜鹊**：从上面扑过来，不打就啄你，掉一个礼物；打中就飞走。
  - **路边的纸箱和充气人偶**：打飞加分，纯好玩。

### 5.3 协议 v1（向下兼容 v0）

| 方向 | 消息 | 意思 |
|---|---|---|
| 板子 → 游戏 | `pu` | 出拳（`pu:1` 也认，和 `jp:1` 一样宽松） |
| 板子 → 游戏 | `bl` | 按铃 |
| 游戏 → 板子 | `ko` | 出拳打中了 |
| 游戏 → 板子 | `warn:car` / `warn:ped` / `warn:hole` | 自己这条路上 25 m 内有车、有人、有坑，每个东西只发一次 |
| 游戏 → 板子 | `turn:-1` / `turn:0` / `turn:1` | 开始左弯、回到直道、开始右弯（可选，看时间） |

- **兼容**：第一课的 starter 和 T1–T6 答案都用 `if/elif` 判断消息，不认识的消息会自动跳过，所以 v1 的游戏照样能跑 v0 的学生代码（M3 要有回归测试证明）。`hi:v1/v2` 不变，`Messages.ProtocolVersion` 改成 `"1"`。
- **要一起改的地方**：
  - `CommandParser.cs` 和外壳的 `classify()`，两边要一致；
  - `docs/protocol.md`；
  - 外壳的统计行；
  - 键盘：F 出拳、R 按铃（已做）；
  - 模拟器：P 键当"摇一摇"，要先确认官方模拟器能不能模拟手势；
  - 积木插件。

### 5.4 积木和第二课

- **通用积木**（`microbit-blocks.js`，以后别的游戏也能用）：加"当摇一摇时 / 当出现某个手势时"，生成 `accelerometer.was_gesture("shake")`。
- **CityScooter 插件**：加三类积木：
  - "出拳"、"按铃"两个动作积木；
  - "当游戏说"的下拉里加 `ko` 和三种 `warn`；
  - 可选"当路拐弯时"。
- **第二课的任务方向**（教材由老师或 GPT #2 写）：
  1. 摇一摇出拳；
  2. V2 用 logo 触摸按铃，同时放铃声；V1 用引脚 1；
  3. 收到 `warn:ped` 自动按铃，这是"事件 → 反应"；
  4. 收到 `turn:` 在 LED 上显示箭头；
  5. 挑战：只靠 `warn:` 消息，不看屏幕骑 20 秒。

## 6. 美术需求（技美和资源管线智能体）

规格照 `docs/art/perf-budget.md` 和 `docs/art/comic-city-standard.md`：

- **障碍物和人**：不超过 1.5k 三角形（车放宽到 3k）、1 个材质。
- **着色器**：必须用 `ComicVertex` 和 `ComicOutline`，否则不会跟着假拐弯走。
- **碰撞体**：用 BoxCollider。
- **数量上限**：同屏最多 6 辆会动的车、8 个人。

| 素材 | 说明 |
|---|---|
| 警车 | 可以拿 Kenney Car Kit 的 `police.fbx` 改成漫画风；白底、蓝白格子带、POLICE 字样、警灯；警灯用顶点色或材质属性闪，**不要新增着色器关键字** |
| 路政维修车 | 小卡车加箭头灯板，橙黄斜纹，不带真实机构标志 |
| 普通车 3～4 种 | Kenney 的 sedan、hatchback、suv、van、taxi 改风格；有车头灯（对向车要闪灯） |
| 路牌 | ROAD WORK AHEAD、TAKE A DETOUR（左右箭头两种）、PREPARE TO STOP |
| 路政工人、交通指挥员 | 荧光背心带反光条、安全帽；指挥员拿 STOP/SLOW 牌 |
| 无盖窨井 | 黑洞加掀开的盖子，四周 2～3 个锥桶 |
| 行人 4～6 种 | 用拼件做（身体、两条腿、两只手是分开的节点），走路靠程序摆动，**不用骨骼动画**，网页版负担小；换配色出变化 |
| 对手车手 | 复用骑手模型，换配色 |
| 喜鹊 | 黑白小鸟，两片翅膀能扇 |
| 漫画字 | POW!、DING!、HONK!、Sorry!、!，做成一张贴图集，用面向镜头的面片显示 |
| 音效 | 喇叭、警笛"呜"一声、车铃、出拳风声、喜鹊叫、拐弯轮胎声 |

美术没做完之前，玩法先用灰盒占位（`PlaceholderTrack` 现在就是这么做的），**两边可以同时开工**。

## 7. 场景切换（以后做，现在先守的约定）

以后可以换场景：珀斯市中心（现在）、Fremantle 港口、Kings Park、Scarborough 海滩，还有学校所在的 Rockingham 海滨。做法是每个场景一个主题资源加一套天空和配色，场景之间放一个过渡路段，天空和配色渐变过去。**现在就要守的约定：**

- 玩法代码里不写任何"这是哪个场景"的判断，场景的不同只体现在主题资源里：路段、障碍、路段事件、礼物。
- 新的预制体都用漫画着色器和统一的配色，换场景时才能跟着换。
- 路段事件只引用预制体，不写死坐标以外的场景信息。

## 8. 测试和验收

- **帧率**：机房电脑、Mobile 画质，在最忙的时刻（路政区、2 辆对向车、4 个行人、正在拐弯）不低于 30 fps，Batches 和三角形在预算以内。
- **可解性**：每个路段事件都能通过第 4.1 节的编辑器测试。
- **不穿模**：会动的车在 15 fps 和 30 fps、当前最高速下都撞得上，不会穿过去（PlayMode 测试）。
- **假拐弯**：骑手前 32 m 内画面没有偏移；场景卸载后全局变量清零，沿用 `ComicMainSceneTests` 现有的写法。
- **协议**：`CommandParser` 和外壳 `classify()` 对新命令的测试；第一课的 starter 和 T1–T6 答案在 v1 游戏里照常工作。
- **积木**：新积木生成的代码在模拟器的 V2 和模拟 V1 下都能跑，没有报错（`tools/shell-tests/blocks.test.js`）。
- **真板子**：周五机房，V1 和 V2 各一块，试出拳、按铃和 `warn:` 消息。
