# v0.6 精修现有场景，线路沿线的交界统一起来

写于 2026-11-11（周三）。分支 `feat/v0.6-polish`，从 `main`（v0.5 已上线）开出。老师的原话："开始精修现在的场景吧，场景之间的切换（铁路线沿线）应该统一一下，现在断断续续的。"

## 现在的问题（看图）

`art-src/districts/route/boundaries/` 里是沿真实路线在每个交界处拍的图（交界前 60 米、前 20 米、后 20 米）。几乎每一处都是同一个样子：

- **到了交界，场景散成一块"树篱 + 草地 + 几棵树"的空地。** 每个交界都长一样，像同一个公园出口。这是 v0.3 契约里"进出口路段要平静下来（矮楼、树、树篱、矮墙）"造成的，那条规则是给互不相干的市区场景定的。
- **铁路（南线是高速公路加铁路）在交界处断掉。** 东线 14 个场景本来是沿着同一条 Midland 线骑，结果每过一个门牌，轨道、围栏、接触网就没了，过几十米又从头出现，样子还不一样：围栏有黑色栅栏的、有玻璃网片的；轨道离路的远近不同；电车的画法不同。
- **铁路换边。** 东线 McIver 到 Bassendean 铁路在左边，Success Hill 到 Midland 在右边，中间没有任何交代。
- **路面一段一个样。** 灰沥青、红色共享车道、红褐沥青直接对接；人行道一会儿浅色石板，一会儿红砖，一会儿草。
- **远景在每个交界沉下去再升起来**，哪怕前后两个场景的地平线是一样的。

看这几张最清楚：`19-mtlawley-to-maylands-before20m.png`、`21-meltham-to-bayswater-before20m.png`、`24-bassendean-to-successhill-before20m.png`、`09-murdoch-to-cockburn-before20m.png`、`11-aubingrove-to-kwinana-before20m.png`。

## 新规则：沿线的东西不能断

下面的规则**取代** v0.3 里"进出口路段平静下来"的写法，适用于东线全部场景和南线沿高速公路的场景。主干（UWA 到 CBD）的交界也按第 3、4 条的精神改。截面契约不变（每一块首尾：路 halfWidth 4、人行道 4、高 0.2）。

1. **走廊连续。** 一条线有一条"走廊"贯穿始终：
   - 东线：Midland 线铁路（道砟、两股轨道、接触网门架、围栏、电车）。
   - 南线 Canning Bridge 到 Aubin Grove：Kwinana Freeway 和中间的 Mandurah 线铁路。
   - 走廊穿过这条线上**每一块**路段，包括每个场景的进口块和出口块，从 z = 0 到块尾，不留空。
2. **块的两端是这条线的标准走廊截面。** 和路的截面契约一样：块中间可以变（车站的站台、高架、桥、车辆段、隧道口），但到块的两端必须回到标准截面：同一侧、同样的横向位置和高度、同样的围栏、同样的轨道。这样任意两块首尾相接都对得上，不管是同一个场景里的两块，还是两个场景的交界。
   - 门架按固定节奏放（每块 40 米，放在块内同一个位置），接触网线在块端的高度和横向位置固定，连起来是一条不断的线。
   - 电车用同一套画法（A 系列、B 系列），不要每组一个样。
3. **交界不是公园。** 进口块和出口块是这个场景自己的一部分，只是比中间安静：走廊照常；另一侧用这条线统一的"街边"收尾（矮石灰岩墙、草边、同一种行道树按固定间距），不用树篱围出来的大草地。两个场景的出口和进口放在一起，看起来是一条街自然地从一个地方过渡到下一个地方。
4. **路面在场景自己的块里过渡，不在交界线上硬切。** 每条线定一种"交界路面"（东线：灰沥青路、浅色石板人行道）。场景自己用红色共享车道或别的铺装的，在自己的进口块、出口块里用一个看得懂的过渡收回到交界路面：一条收边石带、"SHARED PATH" 的起止标线、斑马纹。交界线两边永远是同一种路面。
5. **铁路换边要有交代。** 东线：McIver 到 Bassendean 铁路在左（−X），Success Hill 到 Midland 在右（+X）。换边放在 Success Hill 的进口块：路一直是下坡，让铁路保持水平一两块，路降下去以后铁路从上面斜跨过去（斜交的钢梁桥），在另一侧沿路堤降回路面高度。骑的人从铁路桥下穿过，之后铁路就在右边了。
6. **起点和终点。** McIver 的进口块（从 CBD 来）：铁路从一座路桥下的隧道口钻出来。Midland 是终点：止冲挡之后轨道结束。
7. **远景。** 系统已经改了：相邻两个场景如果引用**同一个** farScenery 预制体，交界处远景不再下沉。地平线一样的相邻场景应该共用一个预制体（例如一组里的三个场景）。地平线确实不同的照旧。

## 精修

范围：除 West Perth（技美的街道）以外的所有老场景。东线昨天刚做完，这次只改走廊和交界。

**做法：先骑一遍，再动手。**

1. 沿场景每 20 米渲染一张骑手视角的图（每个生成器的截图测试里加一个 ride-through），加上交界图。
2. 对着图给每个场景写一张"最差的十处"清单，放在 `art-src/districts/<id>/previews/polish/NOTES.txt`。昨晚东线的成品是新标准，拿来并排比：`art-src/districts/mtlawley/previews/09-astor.png`、`claisebrook/previews/09-cove.png`、`eastguildford/previews/09-chapel.png`、`guildford/previews/03-guildford-hotel.png`。
3. 从最显眼的改起，改完重新渲染，留前后对比图（`polish/before-*.png`、`polish/after-*.png`）。至少两轮。

**常见的毛病**（按老师最可能注意到的排）：
- 方块树、方块灌木、方块动物；同一棵树复制一排。
- 立面是一张平板，或者同一栋楼连着重复；屋顶光秃秃。
- 一长段什么都没有，或者只有草和墙。
- 东西浮在半空、插进地里、互相穿过；共面闪烁（z-fighting）；贴在地面上的细四边形远处闪（铁丝网、标线）。
- 地面材质硬切；人行道和建筑之间有缝。
- 远景只剩雾色的浅块，看不出是什么。
- 牌子上的字认不出（3 像素宽的 N、W、M 要用 5 像素宽的）。
- 地标不像：对照 `SOURCES.txt` 里的资料，必要时重新上网查。

**不要动的**：
- 玩法布局：车道、跳台和缺口的位置和尺寸、障碍和危险的清单、场景长度。除非是修 bug，并在报告里说明。
- 预算：每块含描边不超过 25k 三角形、8 个渲染器；只用 ComicPalette 和 ComicInk 两个材质。
- 着色器、`Main.unity`、技美的目录、`DistrictSetup.cs`、系统字段（gateway、ambience、sky*、line）。水面现在是顶点色平板，是着色器的事，不在这次范围里。
- 别人的生成器和资源。

### 规则

- **每一块的 z = 0 和块尾都是上面这个截面**（`Shift`、`Lift` 都是 0）。车站、桥、跨线桥只在块中间加东西：站台、天桥的柱子落在护栏线上（11.4、23.7、37.25）或路肩上（9.9），不挪轨道和车道。
- 进口块、出口块从 z = 0 到块尾都有完整的走廊，围栏不换成树篱。
- **离开高速公路要看得见。** Cockburn Central 的商业街不在高速公路边上：进口块里走廊从标准位置向左甩出去 56 米（`Shift = Ease(4, 40, 0, 56)`），绕到第一排楼后面；出口块里再甩回来（`Ease(0, 36, 56, 0)`），块尾回到标准截面。中间五块是街道，没有走廊（真实的高速公路在楼后面平行着走）。
- **Canning Bridge 的进口**接 Mounts Bay Rd：走廊不是一开始就在那里，而是从左边 34 米外、5 米高的引桥路堤上降下来，到 z = 30 落到标准位置。
- **另一侧的"街边"**（进口块的前 14 到 16 米、出口块的后 14 到 16 米）：`StreetEdge`，路肩后面一道 0.55 米高的矮石灰岩墙、一条草带、同一种 peppermint 树固定 10 米一棵（块内 z = 5、15、25、35）；后面要么是道路保留地的灌木（`bush = true`），要么是场景自己的东西（Canning 的河岸、Aubin 的湖岸）。河和湖不在交界线上一刀切：出口块里岸线向外甩开（`Shore`、`LakeShore`）。
- **交界路面** = `SouthLineKit.Path` 的默认样子：灰沥青路（`5C636C`）、白色边线、白色中线虚线 3 米 / 每 8 米、自行车标志；路肩是灰色混凝土（`CBC7BC`）加米色路缘石。Canning Bridge 和 Aubin Grove 全程就是这个路面。Murdoch 的红沥青、Cockburn 的街道在自己的进口块 z = 14、出口块 z = 26 处换成交界路面，换的地方有一条 0.7 米宽的石灰岩铺石带，两边各一条白线（`Threshold`）；Cockburn 进口在铺石带后面还有一条斑马线。Aubin 的 Estate 块（有车的小区街道）两头各留 6 米交界路面，同样用铺石带过渡。
- 远景没有共用：四个场景的地平线确实不一样（河对岸的 Applecross、医院和灌木林、镇中心、湖）。要共用就得把这些地标从远景挪进路段里，换成一个只有 Darling 山脉、树带和屋顶的通用远景；这次没做。

### 接口

```csharp
using S = CityScooter.EditorTools.Districts.SouthLineKit;

// 普通的沿线块（在 K.Begin、P.Init 之后，CqChunkDraft d）
S.Path(d, 0, 40);                                     // 交界路面；自己的颜色：S.Path(d, 0, 40, 红, 暖灰)
S.Freeway(d, 0, 40);                                  // 标准走廊，z = 0 到块尾
S.Freeway(d, 0, 40, new S.Corridor { Far = S.FarSide.NoiseWall, Seed = 51 });
S.Train(d, 1, 2, 20);                                 // 南行轨道上一列车，占 z = 2 到 20（每节不超过 24 米）
S.IslandPlatform(d, 0, 40, 2, 20, "AUBIN GROVE");     // 站台，雨棚 z = 2 到 20，站名牌

// 进口块：前 14 米交界路面，铺石带，之后是自己的路面；另一侧是街边
S.Path(d, 0, S.SurfaceChange); S.Path(d, S.SurfaceChange, 40, 红, 暖灰); S.Threshold(d, S.SurfaceChange);
S.StreetEdge(d, 1, 0, 16, 12f, seed: 91, bush: true);

// 离开高速公路（镇中心，或者线路离开高速公路的地方）
var leave = new S.Corridor { Shift = S.Ease(4, 40, 0, 56) };   // 0 到 56 米，平滑
S.Freeway(d, 0, 40, leave);
float y = S.VergeY(leave, x, z);                      // 路和走廊之间那片草地在 (x, z) 处的高度，种树用
```

`S.Corridor` 的字段：`Shift`、`Lift`（z 的函数：整条走廊向左挪多少、抬高多少）、`Deck`（桥：没有路肩，桥面板加桥墩，水由场景自己画）、`Fence`、`GapFrom / GapTo`（路肩和围栏在这一段断开：水渠从路下面穿过去）、`Far`、`FarTo`、`Cars`、`Seed`。其余：`S.Ease`、`S.NameBlock`、`S.Text / S.TextWidth`（像素字，M、N、W 是 5 像素宽）、`S.TrainSample`（给图集和远景用的散装火车）。所有数字都是 `public const`（`S.FenceX`、`S.RoadA0`、`S.TrackA`、`S.WireY`、`S.MastZ0` ……）。

画的时候是"平的"（高度相对路面），地面和标线进 `d.Road`，围栏、护栏、电杆进 `d.SlopedFrontage`（这两个在写块的时候跟着坡度剪切），树、车、火车在工具里剪切好再进 `d.Deep`、`d.Landmark`、`d.Props`。一块标准走廊约 5500 个三角形（含描边）。

### 给 Kwinana（南线 B）

Aubin Grove 的出口块在 z = 40 处是标准截面：围栏 8.45、走廊完整、路面是交界路面、右侧是街边（矮墙、草带、树）加甩开的湖岸。Kwinana 的进口块要从这里接：z = 0 画标准走廊，然后让它离开，例如

```csharp
S.Path(d, 0, S.SurfaceChange);                                    // 再换成 Kwinana 自己的路面，S.Threshold(d, 14)
S.Freeway(d, 0, 40, new S.Corridor { Shift = S.Ease(4, 40, 0, 60), Far = S.FarSide.NoiseWall });
S.StreetEdge(d, 1, 0, 14, 12f, seed, true);
```

对面用 `NoiseWall` 才和 Aubin Grove 接得上（Aubin 全程是隔音墙）。
